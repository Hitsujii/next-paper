# NextPaper

A minimal personal blog built with Next.js, MDX and Tailwind CSS.

NextPaper uses Tailwind Nextjs Starter Blog as its technical foundation and takes visual inspiration from AstroPaper.

## Development

```bash
yarn
yarn dev
```

Open http://localhost:3000.
