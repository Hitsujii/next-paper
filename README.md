# NextPaper

AstroPaper, but for Next.js.

NextPaper is an attempt to bring the clean and simple AstroPaper style into a Next.js project.

It uses Tailwind Nextjs Starter Blog as the base, so MDX, tags, RSS, sitemap, SEO defaults and layouts are already included.

## Features

- Next.js, MDX and Tailwind CSS
- Tags, RSS and sitemap
- SEO-friendly defaults
- Light and dark mode
- Multiple post layouts
- Projects page
- AstroPaper-inspired design

## Development

```bash
yarn
yarn dev
```

Open http://localhost:3000.
