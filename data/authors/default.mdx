NextPaper is a minimal, accessible and SEO-friendly blog theme built with [Next.js](https://nextjs.org/) and [Tailwind CSS](https://tailwindcss.com/).

![NextPaper](/static/images/twitter-card.png)

NextPaper provides a solid foundation for blogs, documentation, projects and portfolios with full MDX support, built-in dark mode, search, RSS, newsletter support and a clean layout that works out of the box.

The blog posts in this template can serve as guides, docs or example articles, making NextPaper a flexible starting point for your next content-driven site.

## Features

NextPaper comes with a set of useful features that make content publishing easy and effective:

- SEO-friendly
- Fast performance
- Light & dark mode
- Highly customizable
- Organizable blog posts
- Responsive & accessible
- Static search index
- RSS, sitemap and tag pages
- Newsletter integration
- Projects page

and so much more.
